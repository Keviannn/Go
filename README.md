# Go Learning
This repository contains my efforts to learn the programming language Go.

## Motivation
As someone passionate about performance programming, I've spent my whole time at university (5 years) writing C, and explored HPC through an university course using OpenMP, OpenMPI, CUDA, Valgrind and Perf. 
I wanted to try a more modern and flexible language that also makes the most of the hardware, and I landed on Go.
